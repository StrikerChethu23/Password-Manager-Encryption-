Project Overview:
The Password Manager with Encryption is a secure, professional-grade password management application that stores and manages your passwords with military-grade encryption. It provides a safe way to store, generate, and manage all your passwords with advanced security features.

Key Features
Advanced Encryption
- **AES-256-CBC Encryption** - Military-grade encryption
- **PBKDF2 Key Derivation** - 100,000 iterations
- **Unique Salt & IV** - For each encrypted entry
- **Master Password Authentication** - Single master key

assword Management
- **Add/Edit/Delete** - Full CRUD operations
- **Secure Storage** - Encrypted database
- **Favorites** - Mark important passwords
- **Categories** - Organize by category
- **Search** - Quick password search

Password Generation
- **Customizable** - Length, character types
- **Memorable Passwords** - Word-based passwords
- **Strength Analysis** - Real-time strength feedback
- **Breach Detection** - Have I Been Pwned integration

Security Features
- **Auto-Lock** - After inactivity (5 minutes)
- **Clipboard Auto-Clear** - After 30 seconds
- **Security Questions** - For account recovery
- **Audit Log** - Track all actions
- **Breach Detection** - Check for compromised passwords

Data Management
- **SQLite Database** - Secure local storage
- **Export/Import** - JSON format
- **Backup & Restore** - Full vault backup
- **Database Optimization** - VACUUM support

Additional Features
- **Statistics Dashboard** - Vault statistics
- **Category Management** - Custom categories
- **Favorite System** - Quick access to important passwords
- **Last Used Tracking** - Monitor password usage
